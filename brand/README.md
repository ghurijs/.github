# Ghuri brand assets

*Ghuri* (ঘুড়ি) is Bengali for kite. The mark is a four-facet paper kite with a tail of two bows;
the wordmark is a monoline lowercase "ghuri" whose i-dot carries the kite's orange.

| File | Use |
|---|---|
| `logo-light.svg` / `logo-dark.svg` | Mark + wordmark, for light / dark backgrounds |
| `wordmark-light.svg` / `wordmark-dark.svg` | Wordmark only |
| `mark.svg` | Kite with tail |
| `favicon.svg` | Kite body only, square, for small sizes |
| `avatar.svg` / `avatar.png` | 512×512 avatar (GitHub org, npm) |
| `social-preview.png` | 1280×640 repository social preview |
| `banner-dark.png` | 1280×640, dark variant |

## Regenerating

Every file is generated by `generate.mjs`:

```bash
npm i @resvg/resvg-js
node generate.mjs ./out
```
